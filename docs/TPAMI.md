# 极简模式已移除

从 2.1.2 起，TPAMI 极简／精简模式已取消。界面入口、独立缩写与字段删减规则、`--tpami-minimal` 参数均已移除。旧任务设置和旧 API 查询参数不会重新开启该模式。

使用普通的 **保留 URL** 与 **使用期刊／会议缩写** 选项即可。作者列表和月份保留；只有清单内会议论文在开启缩写时省略重复出版社，书籍、章节、技术报告和 SAE 条目保留。最终作者显示与排版由 LaTeX 样式决定。

arXiv 标识与来源已有的编号会自动保留在可显示字段中，包括关闭 URL、开启缩写时。已有任务可直接重新导出，无需重复抓取。
